# desktop-themes

The live ASCII wallpapers and color themes of [themes-for-claude](https://github.com/0toshigami/claude-desktop-themes)
(MIT, 0toshigami), moved onto Claude Desktop's own theme API. The original painted the app through a browser
extension loaded with `REACT_PROFILE=1`, which Claude Desktop stopped loading; this version needs no extension.

Type `/themes` in a Code session in Claude Desktop, pick a wallpaper or a color theme, and tune motion, speed, cell
size and the chat backdrop from the strip. "Claude's own" goes back to the app's look.
