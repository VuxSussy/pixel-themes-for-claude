# pixel-themes-for-claude

Live pixel-art and ASCII wallpapers and color themes for Claude Desktop's Code tab, painted through Claude Desktop's
own theme API. Twelve animated scenes (Moonlit, Clawd, Koi Pond, Neon Rain, Snow Cabin, Star Voyage and more) and five
color themes, picked from a strip above the prompt with `/themes`.

Based on [themes-for-claude](https://github.com/0toshigami/claude-desktop-themes) by 0toshigami (MIT): its scenes and
themes, moved off the browser extension that Claude Desktop 6.28899.2 stopped loading.

## Install

At the prompt of a Claude Code session:

```
/plugin install desktop-themes --marketplace VuxSussy/pixel-themes-for-claude
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```bash
claude plugin install desktop-themes --marketplace VuxSussy/pixel-themes-for-claude
```

## Use

In a Code session in Claude Desktop, type `/themes`. Pick a live wallpaper or a color theme; set the style (pixel art
or ASCII), speed, pixel size and how much the chat panels frost over the wallpaper. "Claude's own" goes back to the
app's look. The theme you pick carries over to new sessions.
